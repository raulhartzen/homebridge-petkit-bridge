Companion plugin for petkit-bridge. Run the bridge first, then point this plugin at it.

First, install the bridge

This plugin talks to petkit-bridge, a small service that holds your PetKit account and exposes it on your network. It does not seem to be running yet. On the machine that should run it (this one is fine):

mkdir petkit-bridge && cd petkit-bridge curl -O https://raw.githubusercontent.com/raulhartzen/petkit-bridge/main/.env.example curl -O https://raw.githubusercontent.com/raulhartzen/petkit-bridge/main/docker-compose.example.yml cp .env.example .env # fill in your PetKit account and pick a token cp docker-compose.example.yml docker-compose.yml docker compose up -d

Full instructions: petkit-bridge Quick start. Once it is running, press Search again.

Bridge connection

Checks that the bridge URL and token below work, and lists the devices it exposes — without saving anything.
